# Nmap
- Nmap is a footprinting tool
- This is the first step of hacking where you find information about the target or website
## Video 1
- To open nmap in the kali linux terminal start by typing 'sudo bash' to open the root.
- Then type nmap --help to display the nmap manual
- Nmap gives you a free testing environment at scanme.nmap.org
- nmap -V -A scanme.nmap.org ('V prints the version number/address name. A enables OS detection, version detection, script scanning, and traceroute')
- you can also scan a range of IP Addresses using 'nmap -v -sn 192.168.0.0/16 10.0.0.0/8'
- Use NirSoft website to check IP's from different countries
- Use nslookup to search for the IP address for a certain website or search the website for a certain IP address
- e.g: nslookup scanme.nmap.org
